This is network-level exposure reduction, not patching. Isolating a port stops it being reachable from this scanner. The service keeps running, its software is unchanged, and the underlying vulnerability remains present on the target.
Nothing here happens automatically. A candidate reaches ALLOW only after every safety rule passes, and an action is sent only when an operator confirms it explicitly. The rollback command is computed and stored before the rule is applied, the change is verified by rescanning, and the rule auto-reverts after {{ safety.remediation_ttl_minutes }} minutes.
