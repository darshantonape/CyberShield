How to read this report.
  • Every CVE is a candidate: a version string resembling a CVE's affected software is not proof of vulnerability or exploitability, and no exploitation was attempted.
  • "Version unknown" / "undetermined" is not "clean" — the service could not be identified.
  • "Exposure reduced" means a port's reachability changed as observed by this scanner; the service kept running and no software was patched.
  • A failed, unreachable, partial or uncorrelated scan is reported as such, never as a clean result.
