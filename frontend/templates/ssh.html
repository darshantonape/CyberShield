Why remediation needs SSH. CyberShield's only remediation action is a firewall rule on a laboratory target, and that action is only acceptable because it can be undone. Undoing it means running the stored rollback command on the target, which happens over SSH. A management channel that is misconfigured or unreachable therefore turns a reversible action into a rule that sits on the target until its TTL expires. Check it here before approving anything.
What is never shown or logged. Private keys and passwords. This page reports only the key's path, whether the file exists, and its permission bits — never its contents and never a fingerprint. Password authentication is not implemented at all: allow_agent and look_for_keys are both disabled, so only the one configured key is ever offered.
